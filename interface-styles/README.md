# SterSU Interface Styles

This directory is generated by `scripts/generate-interface-style-store.ps1` in the SterSU source tree.

`catalog-v1.json` and its signature remain frozen for older Managers. The generator writes `catalog-v2.json`, which must be signed with `scripts/sign-interface-style-store-v2.py` and the external `STERSU_INTERFACE_STYLE_V2_KEY` before publication. Never commit the private key. The signing key was rotated on 2026-10-09; updated Managers trust both the current and previous v2 public keys.

## Retired styles (2026-10-09)

All five Rain styles, Windows Fluent, Cloud town, Lava valley, Rust wasteland, and Star voyage are no longer published. Their package files were removed from the store; existing locally installed copies are not automatically deleted.

## Frosted glass, clear revision (2026-10-09)

The updated `liquid-glass-clear-20261009.ksstyle` uses a cool-white light palette and a blue-gray dark palette, softer borders, denser readable surfaces, and no refraction or chromatic aberration. Both bundle and theme versions remain v3 because released Managers require them to match. The signed SHA-256 change identifies this update.

Refresh the interface-style store and update or reinstall **Frosted glass** to apply the new palette and material parameters. Cleaner shared card rendering, the simplified home status panel, and the denser navigation fallback also require a Manager build containing the corresponding UI changes. Downloading a resource package cannot replace the Manager's rendering code.

The previous `liquid-glass.ksstyle` is unchanged so cached and legacy signed catalogs remain valid. Maintainers can update only this entry with `-StyleIds liquid-glass` when running the generator, then sign the resulting v2 catalog before publishing; unrelated styles retain their published metadata and package hashes.

Each `.ksstyle` file is a data-only ZIP bundle. Four-season bundles contain their wallpaper. Pixel, frosted-glass, and sidebar-widget bundles contain their full palette, scene, animation, motif, chrome, and material parameters in a strict v3 declarative theme resource. Packages cannot contain scripts, DEX, native libraries, or arbitrary Web content. The Manager verifies the signed catalog, fixed GitHub URL, package and resource SHA-256 values, byte limits, ZIP entry allowlist, exact schema fields, numeric limits, engine, and variant before atomically installing a style.
