# 小米天气侧栏接口说明

侧栏天气可在手动填写、自定义 HTTPS API 与小米天气之间选择。小米天气模式使用小米主题设计师文档公开的本机 ContentProvider 接口：

`content://weather/actualWeatherData/1`

接口文档：[小米天气新接口](https://zhuti.designer.xiaomi.com/docs/blog/weatherApi.html#%E5%B0%8F%E7%B1%B3%E5%A4%A9%E6%B0%94%E6%96%B0%E6%8E%A5%E5%8F%A3)。`/1` 是官方建议的本地优先模式；本地数据超过一小时后，天气应用可能自行联网更新。SterSU 读取当前温度、天气现象、城市名称、温度单位、天气类型代码和发布时间，用于侧栏展示，并复用原有的前台刷新间隔及本机缓存。

天气小图标优先使用接口返回的 `weather_type` 代码（官方定义的 0–25）；缺失或未知代码才根据天气现象文字归类。图标类别与读数一起缓存在本机，重新打开侧栏时不会退回未知图标。

在设置页选择“小米天气”不会查询接口。用户阅读启用前声明并点击“同意并启用”后，侧栏才会访问本机天气提供方。切回“手动填写”即停止后续查询。此模式不申请设备定位权限，也不向 SterSU 服务器发送天气读数；位置由小米天气应用中的选择和其自身数据策略决定。设备未安装小米天气、未提供该接口或拒绝访问时，侧栏会显示不可用，不会改用其他未经选择的数据源。

本项目没有复制小米天气应用的源码、图标或天气数据集。接口归小米及其相关权利人所有；SterSU 不是小米官方产品，也不代表小米提供兼容性保证。本说明不改变项目及第三方文件的既有许可证。
