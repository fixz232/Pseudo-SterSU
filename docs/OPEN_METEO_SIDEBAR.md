# Open-Meteo 侧栏天气说明

侧栏中部天气组件支持独立的 Open-Meteo 数据源。用户手动填写纬度、经度和可选显示名称，选择摄氏或华氏及前台刷新间隔；程序使用 Open-Meteo 的 [Forecast API](https://open-meteo.com/en/docs) 请求 `current=temperature_2m,weather_code,is_day`，将温度、天气描述和对应的小天气图标映射到现有侧栏组件。天气图标使用本项目已有图标，不复制 Open-Meteo 的图标资源。

仅选择 Open-Meteo 不会发起请求。设置页先展示启用声明；用户确认后才保存启用状态并请求数据。HTTPS 请求向 `api.open-meteo.com` 发送用户填写的经纬度，服务端也会看到网络 IP；可选显示名称只留在本机。SterSU 不申请设备定位权限，不向自身服务器上传天气读数。侧栏前台显示时按选定间隔刷新，并在本机缓存上次成功读数；失败时显示缓存或不可用，不自动改用其他数据源。切回手动填写可停止后续查询。

小图标按 Open-Meteo 文档中的 WMO 天气代码映射：0/1 为晴朗（夜间显示夜晚），2/3 为多云，45/48 为雾，51/53/55/56/57、61/63/65/66/67 及 80/81/82 为雨，71/73/75/77 及 85/86 为雪，95/96/99 为雷暴。未知代码显示未知天气图标。`is_day` 决定晴朗天气的昼夜图标；温度单位以接口返回的 `current_units.temperature_2m` 校验。

天气数据来源为 [Open-Meteo.com](https://open-meteo.com/)，应用内天气详情也显示来源。其免费 API 条款限定非商业用途，并要求遵守 CC BY 4.0；商用应使用合适的付费方案。具体授权、署名及使用条件以 [Open-Meteo 条款](https://open-meteo.com/en/terms) 为准。本项目的源代码许可证不因此改变，也没有将 Open-Meteo 服务或数据集并入仓库。发布或商业使用前应再次核对服务条款及所用计划。
